# Shiva Gaddam Portfolio

A responsive Next.js portfolio with an NFS-inspired visual language and three semantic themes.

## Everyday edits

- Identity, navigation, section headings, experience, principles, and notes: `content/portfolio.ts`
- Skills and marquee items: `content/skills.ts`
- Case studies: `content/work.ts`
- Theme order and labels: `content/themes.ts`
- Theme colors: `styles/theme.css`
- Section presentation: `components/sections/`

## Commands

Run `npm run dev` locally and `npm run build` before release.

See `docs/architecture.md` for the maintenance rules.
